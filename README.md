# 각궁 점화장 제작도면 생성기

각궁(부린활)을 따뜻하고 마른 상태로 보관하는 **점화장**의 제작도면을 만드는 윈도우 프로그램입니다.
치수와 활 장수를 입력하면 조립도·부재도·거치대 형판·밀폐 상세·재단표를 만듭니다.

- **PDF** (A3 5장): 조립도, 부재도(사개 손 포함), 거치대 상세(가능하면 1:1 형판), 밀폐·단열 상세(1:1), 재단표·철물·전기
- **DXF** (1:1): 부재 전개 외곽, 거치대 형판 — CAD, CNC, 레이저용
- **CSV**: 재단표와 철물·전기 목록 (엑셀에서 열림)

## 내려받기

[Releases](../../releases)에서 `GakgungJeomhwajang.exe`를 받아 실행하면 됩니다. 설치는 필요 없습니다.
최신 빌드는 [Actions](../../actions) → 최근 실행 → Artifacts에서도 받을 수 있습니다.

> 처음 실행할 때 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요(서명되지 않은 프로그램이라 뜨는 경고입니다).

## 구조

- **문**: 천판 아래에서부터 높이 500의 양문 여닫이
  - 자석 캐치(문틀 띠에 매립)로 저절로 열리지 않음
  - 문 아래쪽은 고정된 아래 앞판
- **하부 공간**: 안높이를 설정할 수 있음
  - 선반 윗면이 문 하단보다 높아지면 입력 오류로 처리
  - 위아래 공간 사이는 통풍 슬롯이 있는 착탈식 선반(선반받이 위에 얹음)
- **온도조절기·전원**
  - 온도조절기: 아래 앞판에 타공(기본 160×80, 최대). 왼쪽·오른쪽 선택
  - 전원 리셉터클(IEC 인렛): 같은 쪽 뒷판 아래에 수평 배치. 몸체 타공 32×22, 나사 간격 40
- **몸체**: 겉판(레드파인). 천판·지판과 옆판을 사개로 짜고, 뒷판과 아래 앞판은 홈에 끼움
- **밀폐·단열**
  - 벽: 겉판 + 단열재 + 면상필름 + 삼나무 속판
  - 단열층 앞 둘레에 원목 문틀 띠를 두르고 문이 여기에 닿음
  - 문 뒤의 단열 플러그가 문틀 띠 안으로 들어감
  - 가스켓은 선택, 두께 입력 가능
- **열원**: 면상필름(뒤·위·아래·좌·우 중 선택) 또는 하부 바닥의 PTC 히터
- **거치대**: ① 삼각 받침 2개, ② 둥근 막대 2개, ③ 줌걸이 1개 중 선택
  - 앞끝은 문 안쪽 면에서 5 띄움
  - 활 닿는 부분은 라운드(R) 처리
  - 부린활 *n*장(기본 4장, 1장 50mm)을 깊이 방향으로 나란히 걺
- **여유 검사**
  - 벌어진 부린활(고자~고자 최대 폭)과 오므라든 부린활이 모두 들어가는지 확인
  - 거치대에 활 *n*장이 들어가는지 확인
  - 문 열린 높이로 활을 넣을 수 있는지 확인

## 직접 빌드 (선택)

Python 3.10 이상이 설치된 윈도우에서 `build.bat`를 실행하면 `dist\GakgungJeomhwajang.exe`가 만들어집니다.

```
py -m pip install -r requirements.txt
py jeomhwajang_gui.py     # GUI 실행
py jeomhwajang_core.py    # 기본값으로 output 폴더에 도면 생성
```

## 파일

- `jeomhwajang_gui.py`: 입력 화면 (탭: 본체 / 단열·밀폐 / 문 / 하부·전원 / 열원 / 거치대 / 부린활)
- `jeomhwajang_preview.py`: 미리보기 (내부 정면 + 측단면, 항목 강조, 여유 검사 표시)
- `jeomhwajang_core.py`: 부재 계산, 여유 검사, PDF·DXF·CSV 생성
- `tools/make_icon.py`: 아이콘 생성
- `.github/workflows/build-windows.yml`: main 브랜치에 올리면 exe를 자동으로 빌드하고, `v*` 태그를 달면 Release에 올립니다.
