# 각궁 점화장 제작도면 생성기

**만든 사람: @용현정 이동철**

각궁(부린활)을 따뜻하고 마른 상태로 보관하는 **점화장**의 제작도면과 3D 모델을 만드는 윈도우 프로그램입니다.
치수와 활 장수를 입력하면 조립도·부재도·거치대 형판·밀폐 상세·재단표와 3D 모델을 만듭니다.

- **출력 파일**: 도면 PDF와 3D 뷰어(HTML)는 항상 만들고, DXF·CSV·OBJ·SketchUp DAE는 화면의 '출력 파일'에서 체크한 것만 만듭니다.
- **PDF** (A3 5장): 조립도(정면·내부·측단면·평단면·배면), 부재도(사개 손·타공·통풍 슬롯), 거치대 상세(가능하면 1:1 형판), 밀폐·단열 상세(1:1), 재단표·철물·전기
- **DXF** (1:1): 부재 전개 외곽, 타공, 통풍 슬롯, 거치대 형판 — CAD, CNC, 레이저용
- **CSV**: 재단표와 철물·전기 목록 (엑셀에서 열림)
- **3D 모델**
  - OBJ(+MTL): Blender, Fusion 360 등
  - DAE: SketchUp → 파일 → 가져오기. 부재별로 나뉘고 단위는 mm
- **3D 뷰어(HTML)**: 인터넷 없이 브라우저에서 열림. 문 열기 각도, 단면 보기, 레이어 켜고 끄기, 부린활 표시(기본: 벌어진 활·오므라든 활을 번갈아 섞어 걺)

## 웹 버전 (설치 없이 바로 사용)

**https://happydc.github.io/Gakgung_jeomwhajang/**

- 브라우저(Chrome, Edge 등)에서 열면 바로 씁니다. 설치가 필요 없고, 스마트 앱 컨트롤이나 Windows 7 문제도 없습니다.
- 처음 열 때 계산 프로그램을 내려받느라 10~30초 걸립니다. 다음부터는 빨라집니다.
- 기능과 도면은 exe와 같습니다. 같은 파이썬 코드를 브라우저 안에서 실행하기 때문입니다([Pyodide](https://pyodide.org)).
- 만든 파일(PDF·DXF·CSV·3D)은 화면의 파일 이름을 눌러 내려받습니다. 입력값은 그 브라우저에만 저장됩니다.

## 내려받기

[Releases](../../releases)에서 `GakgungJeomhwajang.exe`를 받아 실행하면 됩니다. 설치는 필요 없습니다.
최신 빌드는 [Actions](../../actions) → 최근 실행 → Artifacts에서도 받을 수 있습니다.

> 처음 실행할 때 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요(서명되지 않은 프로그램이라 뜨는 경고입니다).

### Windows 7에서 쓰기

Windows 7에서는 Python 3.9 이상으로 만든 exe가 dll 오류(`api-ms-win-core-path-l1-1-0.dll` 등)로 실행되지 않습니다. 그래서 Python 3.8로 따로 빌드한 Windows 7 전용 exe를 함께 올립니다.

| 파일 | 대상 |
|---|---|
| `GakgungJeomhwajang.exe` | Windows 8.1 / 10 / 11 |
| `GakgungJeomhwajang_win7_x64.exe` | Windows 7 64비트 |
| `GakgungJeomhwajang_win7_x86.exe` | Windows 7 32비트 |

- 64비트인지 32비트인지는 **시작 → 컴퓨터(오른쪽 클릭) → 속성 → 시스템 종류**에서 확인합니다.
- 그래도 `api-ms-win-crt-runtime-l1-1-0.dll` 오류가 나면 Windows 7 **서비스 팩 1(SP1)**과 **유니버설 C 런타임 업데이트(KB2999226)**를 설치하세요.
- 3D 뷰어(HTML)는 Internet Explorer에서는 열리지 않습니다. Windows 7에서는 Chrome 109 또는 Firefox ESR 115로 여세요.

## 구조

- **외관**: 귀장석·장석 없이 원목 그대로. 사개 맞춤이 보이고, 원목 손잡이를 씀
- **문 형식** (입력 화면 위쪽 '주요 선택'): 천판 아래에서부터 높이 350(기본, 변경 가능). 두 형식 모두 자석 캐치(문틀 띠에 매립)로 저절로 열리지 않고, 문 아래쪽은 고정된 아래 앞판
  - **양문 여닫이**: 좌우 두 짝. 맞경첩을 문 옆면에 묻어 겉에는 축만 보임. 가운데는 턱맞춤
  - **반닫이**: 앞면 위쪽 문판 한 장이 아래 끝 경첩을 축으로 앞으로 젖혀 열림
    - 문판 양끝에 마구리(기본 45, 세로결)를 촉으로 끼워 휨을 막음
    - 맞경첩 3개(180° 열리는 것)를 축이 앞면 선에 오게 달고, 문판이 바닥(또는 아래 앞판)에 닿을 때까지 완전히 열림. 닿는 각도는 자동 계산해 도면에 표시
    - 지지대 수를 1 이상으로 넣으면 90°에서 멈춰 작업 선반처럼 씀
    - 손잡이는 위 가운데에 가로로 단 원목 손잡이
- **하부 공간**: 안높이를 설정할 수 있음
  - 선반 윗면이 문 하단보다 높아지면 입력 오류로 처리
  - 위아래 공간 사이는 통풍 슬롯이 있는 착탈식 선반(선반받이 위에 얹음)
- **온습도 조절기·전원**
  - 입력 화면 위쪽 '주요 선택'에서 왼쪽·오른쪽을 고르면 조절기와 전원 인렛이 함께 그쪽으로 옮겨짐
  - 온습도 조절기(XM-18형, 앞 테두리 160×80, 깊이 89): 아래 앞판에 몸체 타공(기본 152×72, 실물에 맞춰 조정)
  - 전원 리셉터클(IEC 인렛): 같은 쪽 뒷판 아래에 수평 배치. 몸체 타공 32×22, 나사 간격 40
- **몸체**: 겉판(레드파인). 천판·지판과 옆판을 사개로 짜고, 뒷판과 아래 앞판은 홈에 끼움
- **밀폐·단열**
  - 벽: 겉판 + 단열재 + 면상필름 + 삼나무 속판
  - 단열층 앞 둘레에 원목 문틀 띠를 두르고 문이 여기에 닿음
  - 문 뒤의 단열 플러그가 문틀 띠 안으로 들어감
  - 가스켓은 선택, 두께 입력 가능
- **열원**: 하부 바닥 가운데의 PTC 히터(기본, 230×150×70) 또는 면상필름(뒤·위·아래·좌·우 중 선택)
- **거치대**: ① 삼각 받침 2개, ② 둥근 막대 2개, ③ 줌걸이 1개 중 선택
  - 앞끝은 문 안쪽 면에서 5 띄움
  - 활 닿는 부분은 라운드(R) 처리
  - 부린활 *n*장(기본 4장, 1장 50mm)을 깊이 방향으로 나란히 걺
- **여유 검사**
  - 벌어진 부린활(고자~고자 최대 폭)과 오므라든 부린활이 모두 들어가는지 확인
  - 거치대에 활 *n*장이 들어가는지 확인
  - 문 열린 높이로 활을 세운 채 넣을 수 있는지 확인 (열린 높이 = 문 높이 − 36, 기본값 314 ≥ 벌어진 활 300)

## 기본값

| 항목 | 기본값 |
|---|---|
| 외형 W × H × D | 1000 × 800 × 320 mm |
| 문 형식 | 양문 여닫이 (반닫이 선택 가능) |
| 문 높이 / 하부 공간 안높이 | 350 / 120 mm |
| 겉판 / 단열재 / 속판 / 문틀 띠 깊이 | 18 / 10 / 9 / 20 mm |
| 발 높이 | 18 mm |
| 부린활 | 4장 × 50 mm (궁대 포함) |
| 벌어진 활 / 오므라든 활 | 고자~고자 880, 높이 300 / 560 × 500 |
| 거치대 | ① 삼각 받침, 중심 간격 260, 속 천장에서 85 아래, R8 |
| 열원 | PTC 히터 230×150×70, 하부 바닥 가운데 (또는 면상필름) |
| 조절기 타공(테두리) / 리셉터클 타공 | 152×72(160×80) / 32×22, 왼쪽 |

모든 값은 입력 화면에서 바꿀 수 있습니다. 항목에 마우스를 올리면 오른쪽 미리보기에서 해당 부분이 빨간색으로 표시됩니다.

## 직접 빌드 (선택)

Python 3.10 이상이 설치된 윈도우에서 `build.bat`를 실행하면 `dist\GakgungJeomhwajang.exe`가 만들어집니다.

```
py -m pip install -r requirements.txt
py jeomhwajang_gui.py     # GUI 실행
py jeomhwajang_core.py    # 기본값으로 output 폴더에 도면 생성
py jeomhwajang_3d.py      # 3D 모델·뷰어 생성
```

## 파일

- `jeomhwajang_gui.py`: 입력 화면 (탭: 본체 / 단열·밀폐 / 문 / 하부·전원 / 열원 / 거치대 / 부린활)
- `jeomhwajang_preview.py`: 미리보기 (내부 정면 + 측단면, 항목 강조, 여유 검사 표시)
- `jeomhwajang_core.py`: 부재 계산, 여유 검사, PDF·DXF·CSV 생성
- `jeomhwajang_3d.py`: 3D 메시, OBJ·DAE·3D 뷰어 생성
- `assets/vendor/`: three.js r147 (MIT 라이선스). 3D 뷰어에 넣어 오프라인으로 열림
- `web/`: 웹 버전 (`index.html` 화면, `web_api.py` 파이썬 연결부, `build_site.sh` 사이트 조립)
- `assets/fonts/`: 나눔고딕(OFL) — 웹 버전과 한글 글꼴이 없는 PC에서 도면 글꼴로 사용
- `.github/workflows/pages.yml`: main에 올리면 웹 버전을 GitHub Pages로 자동 배포
- `tools/make_icon.py`: 아이콘 생성
- `requirements-win7.txt`: Windows 7용 빌드(Python 3.8)에 쓰는 패키지 버전
- `.github/workflows/build-windows.yml`: main 브랜치에 올리면 exe(일반용 + Windows 7용 64·32비트)를 자동으로 빌드하고, `v*` 태그를 달면 Release에 올립니다.
